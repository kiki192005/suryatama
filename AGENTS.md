# PT. Suryatama Indonesia - Website Company Profile

Baca `prd.md` untuk kebutuhan dan `info-perusahaan.md` untuk isi konten.

## Tech stack
Next.js (App Router), TypeScript, Tailwind CSS, Framer Motion, next-intl

## Aturan
- Jangan mengarang data perusahaan; pakai hanya isi `info-perusahaan.md`
- Jangan menampilkan pemegang saham, modal, atau jumlah karyawan di mana pun
- Semua teks lewat file terjemahan (id dan en), bukan hardcode di komponen
- Jangan commit `.env*`, `node_modules/`, `.next/`, atau file `.pptx`
- Jangan menaruh rahasia di kode
- Kerjakan per fase sesuai `prd.md`, lalu berhenti dan jelaskan perubahan
- Tanya dulu sebelum menambah library di luar yang tertulis di `prd.md`
